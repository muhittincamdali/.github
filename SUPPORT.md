# Getting help

## Start with the documentation

Each repository's README has a quick start and links to its full documentation (DocC for Swift
packages, published on GitHub Pages), guides and example projects. Most questions are answered
there or in the example code.

## Ask a question or report a problem

| You want to…                        | Go to                                                                       |
| ----------------------------------- | --------------------------------------------------------------------------- |
| Report a bug                        | The repository's **Issues** tab, "Bug report" form                          |
| Suggest a feature or an improvement | The repository's **Issues** tab, "Feature request" form                     |
| Ask how to do something             | The repository's **Discussions** tab when it is enabled, otherwise an issue |
| Report a security problem           | Privately, as described in the [security policy](SECURITY.md)               |

A good report includes the version you use, your platform and toolchain (for example Xcode or
Flutter version), the smallest code that shows the problem, and what you expected to happen.

## Response times

These projects are maintained in my own time. I read every issue and usually reply within a few
days; bugs with a clear reproduction get fixed first.
